# نظام الحضور والانصراف - جمعية إحسان لرعاية الأيتام

## 🤲 نظرة عامة

نظام إلكتروني متكامل لإدارة حضور وانصراف موظفي جمعية إحسان لرعاية الأيتام بدومة الجندل. تم تطويره باستخدام أحدث التقنيات لتوفير تجربة مستخدم سلسة وفعالة.

## ✨ المميزات

### 📋 الصفحة الرئيسية
- تسجيل الحضور والانصراف بضغطة زر واحدة
- عرض الوقت الحالي بالتوقيت المحلي
- عرض سجل اليوم للموظف المحدد
- حساب ساعات العمل تلقائياً
- واجهة عربية جميلة وسهلة الاستخدام

### 📊 صفحة السجلات
- عرض جميع سجلات الحضور والانصراف
- تصفية السجلات حسب الموظف والتاريخ
- عرض حالة الحضور (حاضر، متأخر، غائب، غير مكتمل)
- إحصائيات سريعة للسجلات المعروضة

### 👥 صفحة الموظفين
- إضافة موظفين جدد
- تعديل بيانات الموظفين
- حذف الموظفين
- عرض معلومات الموظف الكاملة (الاسم، المسمى الوظيفي، القسم، رقم الموظف، الجوال، البريد الإلكتروني، تاريخ الالتحاق)

### 📈 صفحة التقارير
- تقارير شهرية مفصلة لكل موظف
- إحصائيات شاملة (أيام الحضور، الغياب، التأخير، ساعات العمل)
- نسبة الحضور لكل موظف
- رؤى الأداء (أفضل حضور، أكثر ساعات عمل، متوسط الحضور)

## 🛠️ التقنيات المستخدمة

- **Next.js 16** - إطار عمل React للتطبيقات الحديثة
- **TypeScript** - للأمان والجودة في الكود
- **Tailwind CSS** - للتصميم السريع والمتجاوب
- **React Hooks** - لإدارة الحالة
- **localStorage** - لتخزين البيانات محلياً

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn أو pnpm

### خطوات التثبيت

1. **تثبيت المكتبات:**
\`\`\`bash
npm install
\`\`\`

2. **تشغيل المشروع في وضع التطوير:**
\`\`\`bash
npm run dev
\`\`\`

3. **فتح المتصفح على:**
\`\`\`
http://localhost:3000
\`\`\`

4. **بناء المشروع للإنتاج:**
\`\`\`bash
npm run build
\`\`\`

5. **تشغيل المشروع في وضع الإنتاج:**
\`\`\`bash
npm start
\`\`\`

## 📱 الاستخدام

### تسجيل الحضور والانصراف
1. افتح الصفحة الرئيسية
2. اختر اسم الموظف من القائمة المنسدلة
3. اضغط على "تسجيل الحضور" عند الوصول
4. اضغط على "تسجيل الانصراف" عند المغادرة

### إضافة موظف جديد
1. انتقل إلى صفحة "الموظفين"
2. اضغط على "إضافة موظف جديد"
3. املأ البيانات المطلوبة
4. اضغط على "إضافة الموظف"

### عرض التقارير
1. انتقل إلى صفحة "التقارير"
2. اختر الشهر المطلوب
3. شاهد التقارير والإحصائيات التفصيلية

## 🎨 التصميم

- واجهة عربية كاملة مع دعم RTL
- تصميم متجاوب يعمل على جميع الأجهزة (الهاتف، التابلت، الكمبيوتر)
- ألوان متناسقة مع هوية الجمعية (الأخضر والأزرق الفيروزي)
- رموز تعبيرية لتحسين تجربة المستخدم

## 💾 تخزين البيانات

يستخدم النظام حالياً `localStorage` لتخزين البيانات محلياً في المتصفح. يمكن تطوير النظام لاحقاً لاستخدام قاعدة بيانات حقيقية مثل:
- MongoDB
- PostgreSQL
- MySQL
- Firebase

## 🔒 الأمان

- جميع البيانات مخزنة محلياً في المتصفح
- لا يتم إرسال أي بيانات إلى خوادم خارجية
- يمكن إضافة نظام مصادقة وتفويض عند الحاجة
