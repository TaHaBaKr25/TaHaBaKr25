# 🤝 المساهمة في المشروع

نرحب بمساهماتكم في تطوير نظام الحضور والانصراف!

---

## 📋 كيفية المساهمة

### 1. Fork المشروع
انقر على زر "Fork" في أعلى الصفحة

### 2. Clone المشروع
\`\`\`bash
git clone https://github.com/YOUR_USERNAME/attendance-system.git
cd attendance-system
\`\`\`

### 3. أنشئ فرع جديد
\`\`\`bash
git checkout -b feature/amazing-feature
\`\`\`

### 4. قم بالتعديلات
- اكتب كود نظيف ومنظم
- اتبع نمط الكود الموجود
- أضف تعليقات عند الحاجة
- اختبر التعديلات جيداً

### 5. Commit التغييرات
\`\`\`bash
git add .
git commit -m "إضافة ميزة رائعة"
\`\`\`

### 6. Push للفرع
\`\`\`bash
git push origin feature/amazing-feature
\`\`\`

### 7. افتح Pull Request
- اذهب إلى صفحة المشروع على GitHub
- انقر على "New Pull Request"
- اشرح التعديلات التي قمت بها
- انتظر المراجعة

## 📝 معايير الكود

### TypeScript
- استخدم TypeScript في جميع الملفات
- حدد الأنواع بوضوح
- تجنب استخدام `any`

### React
- استخدم Functional Components
- استخدم Hooks بشكل صحيح
- تجنب التكرار

### التصميم
- استخدم Tailwind CSS
- اتبع نظام الألوان الموجود
- تأكد من التجاوب

### التسمية
- استخدم أسماء واضحة ومعبرة
- اتبع نمط camelCase للمتغيرات
- اتبع نمط PascalCase للمكونات

## 📋 قائمة التحقق

قبل إرسال Pull Request، تأكد من:

- [ ] الكود يعمل بدون أخطاء
- [ ] تم اختبار التعديلات
- [ ] الكود نظيف ومنظم
- [ ] لا توجد أخطاء TypeScript
- [ ] التصميم متجاوب
- [ ] تم تحديث التوثيق (إن لزم)
- [ ] تم إضافة تعليقات (إن لزم)
